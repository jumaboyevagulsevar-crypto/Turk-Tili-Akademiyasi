# Turk Tili Akademiyasi (LMS Upgrade)

Ushbu loyiha Turk tili o'rganuvchilar uchun zamonaviy va interfaol platforma hisoblanadi.

## Platforma Tarkibi:
- **Client**: React (Vite) frontend.
- **Server**: Node.js (Express) backend.

## Asosiy Modullar:
1. **AI Chat Tutor**: GPT-4 bilan muloqot va xatolarni tuzatish.
2. **Gamifikatsiya**: XP, Level va Leaderboard tizimi.
3. **Smart Flashcards**: Spaced Repetition (SRS) algoritmli kartochkalar.
4. **Progress Analytics**: Vizual grafiklar va tahlillar.
5. **PDF Generator**: Lesson summary export funksiyasi.

## Ishga tushirish:
Battery-included instruksiyalar uchun `client` va `server` papkalaridagi `README.md` larni ko'ring. 
Batafsil ma'lumot uchun `walkthrough.md` artifactini tekshiring.
